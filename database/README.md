# Scripts de base de datos

- `base/`: esquema inicial para crear la estructura en una base nueva.
- `datos-prueba/`: datos ficticios opcionales para desarrollo y demostraciones.
- `migraciones/`: cambios incrementales y módulos adicionales; aplícalos solo cuando el módulo correspondiente lo requiera y una sola vez.

Consulta `../README.md` y `../docs/migracion-seleccion.md` para el orden y las precauciones de instalación. No ejecutes el esquema inicial sobre una base con información que quieras conservar.
